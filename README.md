# Call Center – Business Intelligence & Data Analytics

## Description
This project focuses on analyzing call center performance using Business Intelligence techniques to transform raw data into meaningful insights and support decision-making.

## Technologies
- Python
- PostgreSQL
- PygramETL
- Power BI

## Project Components
- `main.py`: Data processing and ETL implementation.
- `call.sql`: Database creation and SQL queries.
- `dashboard.pbix`: Interactive Power BI dashboard.
- `rapport.docx`: Project documentation.
- CSV files: Original datasets and processed results.

## Project Workflow
1. Data preparation.
2. Database management using PostgreSQL.
3. Data extraction, transformation and loading (ETL).
4. Data analysis and processing using Python.
5. Performance monitoring through Power BI dashboards.

## Objectives
- Analyze call center activities.
- Monitor key performance indicators (KPIs).
- Improve data visualization.
- Support data-driven decision-making.
